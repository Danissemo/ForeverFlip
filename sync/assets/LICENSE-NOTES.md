# Примечания об источниках и правах

Набор подготовлен для проекта ForeverFlip Sync по предоставленному финальному растровому референсу. Векторные элементы — реконструкция этого референса; исходный редактируемый дизайн-файл не предоставлялся. Интерактивные состояния, CSS и численные токены оформлены для реализации; состояния hover, pressed, focus-visible и disabled являются производными проектными решениями.

Этот файл описывает происхождение материалов и не устанавливает отдельную лицензию на весь набор. Права на исходный референс, название проекта и содержащиеся в нём сторонние обозначения сохраняются за их правообладателями.

Segoe UI используется как установленный в системе шрифт. Файлы шрифтов в набор не включены. Живой текст HTML/CSS зависит от наличия Segoe UI; для резервных шрифтов допускаются различия в метриках. Растровые PNG уже содержат отрисованный текст. Во всех экспортированных SVG текст переведён в контуры, включая логотипы, кнопки и сборные превью; текстовых узлов нет, поэтому установленный шрифт для отображения SVG не требуется.

Их присутствие в интерфейсе указывает на соответствующий сервис или игру и не означает официального партнёрства или одобрения. Реконструкция не изменяет применимые права и правила использования этих обозначений.
