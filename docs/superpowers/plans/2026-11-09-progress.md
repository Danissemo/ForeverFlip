# Native operation progress 5.3.1

User requests a progress bar for Full Scan and other actions, plus matching
Auctionator populated-table style. Implement without further design gate.

- Read-only Progress.state maps real controller jobs to waiting/processing/action/
  done/error/stopped states. Show exact processed rows only when total known;
  server waits use moving segment and elapsed time, never fabricated percentages.
- Native footer StatusBar is always visible, shared across sections. Paint it at
  existing controller tick cadence without reranking all deals. Completion, error,
  timeout and Stop must terminate animation. Quote confirmation never auto-trades.
- Include exact search, watch session, quote/receipt waits, manual confirmation,
  pending reconciliation, posting sent, and synchronous planner/calculator results.
- Compact20-unit native table rows (matching inspected Auctionator row template),
  alternating black/gray background, native coin price alignment, quality colors,
  actual cached item levels. Preserve exact links and action semantics.
- Red/green tests, fresh read-only review, full Lua51 suite, LuaLS, version5.3.1,
  backup/install onlyaddonfiles, noWTF writes. No live visual claims.
